# AI Command Center

A local AI assistant built with Python and Ollama.

## Overview

AI Command Center is a command-line AI assistant powered by a locally running large language model.

The project demonstrates local LLM integration, conversational memory, command handling, and modular Python application architecture.

## Features

- Local LLM inference
- Conversational memory
- Interactive command-line interface
- Conversation history
- Clear conversation memory
- Model information
- Command system
- Error handling

## Technology Stack

- Python
- Ollama
- Llama 3.2 3B
- Ollama Python SDK
